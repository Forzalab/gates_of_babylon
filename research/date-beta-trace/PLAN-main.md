2. **Prep (Pillow)** per bg → 1920×1080 PNG: erase Craiyon mark (patch-copy from nearby), LANCZOS upscale, light smoothing, ref placed at full height in the center; wings = the ref's outer columns stretched + blurred + darkened (no mirrored duplicates). Park: ref 9 base, ref 10 cathedral cut from its sky (blue-key mask) pasted small into ref 9's bright sky gap, top-right.
3. **Trace (vtracer)** color / stacked / spline; tune speckle + color precision + layer difference for ≤ ~500 KB per SVG. Output `public/date-beta/trace/{apartment,sitting-room,bedroom,park}.svg`.
4. **One review pass per image** (render 1920×1080 via Playwright, look + score.py dE): list bad physics/placement (wings, warped perspective, floating blobs, mush on faces/text, rain noise, watermark) in `research/date-beta-trace/REVIEW.md`; hand-draw fixes as SVG overlays in each scene component.
