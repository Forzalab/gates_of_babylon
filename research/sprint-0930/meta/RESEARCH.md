# T3 META-LOOP research (short)

## 4th wall in games
- DDLC / Undertale / Stanley Parable / Pony Island: the break lands because the game *remembers across sessions* (Undertale's Flowey knows you reset; DDLC edits its own files) and addresses *the player*, not the avatar. Pony Island flips it inward: the game pulls you into the machine. Sources: https://www.g2a.com/news/features/top-10-fun-games-that-break-the-fourth-wall/ , https://www.watchmojo.com/articles/top-10-video-games-that-break-the-4th-wall , https://thestanleyparable.fandom.com/wiki/Fourth_wall , https://www.researchgate.net/publication/356841341_Breaking_the_Fourth_Wall_in_Video_Games_A_New_Terminology_and_Methodology
- Take: persistent memory ({RUN}, past picks) + real-world facts she "shouldn't" know ({TIME}, {DAYPART}, the room) = the chill. Keep breaks rare so each one counts.

## Crowdwork
- Read the eyes, not the polite smiles; short questions, control the frame, leave room to breathe. https://exactstaff.com/what-stand-up-comedians-know-about-reading-a-room/ , https://funnymuscle.com/upgrade-your-crowd-work/
- Roast *with* the room, not at one person; the target should come out a small hero. https://www.facebook.com/pescagist/posts/crowd-work-can-go-mean-fast-the-better-version-take-the-joke-and-bring-the-audie/1411464347521572/
- Etiquette: picked people are part of the bit only with consent; never punch at looks/identity. https://www.reddit.com/r/Standup/comments/1i54nov/whats_the_etiquette_for_audience_members_who_get/
- Take: "magic trick" = name a thing she can't know (the time, that it's a classroom, someone in the back). Targets = Tony-editable placeholders; only the two consenting people are named specifically.

## Loop writing
- Make repetition fresh: each pass changes one thing and the looper escalates awareness (denial → testing → acceptance). https://lucymitchellauthor.blog/2025/06/23/trapped-in-time-writing-time-loops/ , https://tvtropes.org/pmwiki/pmwiki.php/Main/GroundhogDayLoop , https://www.helpingwritersbecomeauthors.com/movie-storystructure/groundhog-day/
- Take: run 1 = subtle déjà vu, run 2 = "why is everything the same?", run 3+ = both know, and it's fast and flat. Implemented as `vary.run` buckets 1/2/3.
